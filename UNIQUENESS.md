# Отчёт по уникальности решения (VoiceAI)

Документ описывает, какие части решения написаны с нуля для данного проекта,
а какие взяты из сторонних компонентов. Он нужен для проверки уникальности
работы на хакатоне (критерий AE-10).

## Что написано с нуля (авторский код)

Всё приложение, кроме привязок к готовым библиотекам, написано для проекта:

1. **Вставка текста через `SendInput` + `KEYEVENTF_UNICODE`** (`src/insert.rs`).
   Текст печатается как нажатия клавиш с Unicode-скан-кодами. Буфер обмена для
   основной вставки **не используется вообще**: нет ни сохранения, ни
   восстановления, поэтому нет гонки «старый буфер перекрывает текст» — это
   осознанное инженерное решение, отличающее проект от типовых решений
   «скопировать в буфер + Ctrl+V».

2. **Собственный оконно-sinc ресемплер аудио** (`src/audio.rs`). Конвертация
   частоты дискретизации микрофона (48/44.1 кГц) в 16 кГц для Whisper сделана
   вручную: sinc-ядро с окном Кайзера, без алиасинга. Плюс обрезка тишины,
   мягкое шумоподавление и нормализация громкости — всё локальное, без внешних
   DSP-библиотек.

3. **Защита от «галлюцинаций» Whisper** (`audio::has_speech_energy`,
   `MIN_SPEECH_SECONDS`): тихие/пустые записи (быстрое нажатие клавиши)
   не уходят в модель и ничего не вставляют — против типовой проблемы
   «Продолжение следует».

4. **Пост-обработка текста** (`src/postprocess.rs`): слова-паразиты русского
   языка, повторы, пунктуация, абзацы — полностью локальный алгоритм, без LLM
   и интернета.

5. **Архитектура надёжности**: транскрибация в отдельном потоке с
   `catch_unwind`, ленивая загрузка модели, автоперезагрузка после сбоя,
   детерминированный тест single-instance на временном порту.

6. **Логирование и диагностика** (`voiceai.log`): каждая запись логируется
   с длительностью, уровнем сигнала, «сырым» текстом Whisper и итогом —
   по журналу видно, где именно произошла ошибка.

## Что взято из сторонних библиотек (стандартный стэк)

- `whisper-rs` — привязки к whisper.cpp; сама модель `ggml-large-v3-turbo.bin`
  — открытые веса OpenAI/whisper.cpp (MIT).
- `cpal`, `hound` — стандартные библиотеки захвата звука и WAV.
- `global-hotkey` — стандартная библиотека глобальных клавиш.
- `eframe`/`egui` — стандартный GUI-фреймворк.
- `tray-icon`, `winreg`, `windows-sys`, `serde`, `serde_json`, `arboard` —
  стандартные мелкие утилиты (см. `THIRD-PARTY.md`).

Никаких фрагментов кода других решений данного хакатона в проекте нет: работа
велась с нуля поверх описанного выше открытого стека.

## Уникальность с точки зрения критериев

- Оригинальный метод вставки без буфера обмена (разделы K, L, AM-06).
- Локальная «анти-галлюцинация»-защита и диагностический журнал (O, T, AM-19).
- Кроссплатформенный автозапуск и трей, единая копия процесса (B, O-14, AG).
- Собственная предобработка аудио для качества распознавания (C, E, AI).
