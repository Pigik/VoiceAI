# VoiceAI

Диктофон с локальным распознаванием речи: зажали клавишу, сказали, отпустили —
текст появляется под курсором в любом приложении. Распознавание идёт на вашем
компьютере через Whisper (whisper.cpp) или, по желанию, через GigaAM v3.

## Возможности

- Запись по удержанию клавиши **F1** (работает в любом приложении). Клавиша
  переназначается в настройках — подходят функциональные клавиши F1–F24.
  Есть режим «нажал — включил, нажал — выключил».
- Микрофон включается только на время записи: между записями программа его не слушает.
- Распознавание полностью локально: **Whisper large-v3-turbo** (по умолчанию,
  CUDA на Windows / Metal на macOS / CPU на Linux) или **GigaAM v3 e2e-ctc**
  (русская речь с пунктуацией, CPU; скачивается из окна настроек, ~215 МБ).
- **Вставка текста под курсор** (Windows) — без использования буфера обмена.
  Если вставить не удалось, текст кладётся в буфер обмена (Ctrl+V).
- **Пост-обработка текста**: убираются слова-паразиты («ну», «вот», «э-э»),
  случайные повторы слов, расставляются точки и заглавные буквы, длинный текст
  делится на абзацы, речевые дроби и время превращаются в «3/5» и «15:30».
- **Журнал реплик** (кнопка «Журнал»): все расшифровки с датой, числом слов и
  окном, куда вставлялся текст; сводка за сегодня, копирование и удаление записей.
- **Журнал работы** `voiceai.log`: все шаги (сохранение, расшифровка, ошибки)
  с датой и временем — по нему легко понять, что произошло.
- **Режим приватности**: текст расшифровок не сохраняется ни в журнале реплик,
  ни в `voiceai.log`.
- Надёжность: сбой отдельной расшифровки не останавливает программу — следующая
  запись обработается нормально.
- **Настройки сохраняются на диск** (`config.json` в папке данных пользователя)
  и переживают обновление программы; профиль настроек можно экспортировать и
  импортировать.
- **Автозапуск** при входе в систему и **иконка в трее** (Windows): синяя —
  готов к записи, красная — идёт запись. Крестик окна прячет программу в трей,
  полный выход — кнопка «Выход» или меню иконки.
- **Одна копия**: повторный запуск не запускает второе приложение и не мешает первому.

## Режим работы

**Локальный** (без серверной части). Запись, распознавание речи, пост-обработка
текста и вставка выполняются целиком на машине пользователя. Серверного
компонента и телеметрии нет; интернет нужен только для скачивания моделей.

## Готовые сборки (рекомендуется)

Если не собираете проект сами — скачайте готовый архив со страницы
[Releases](https://github.com/Pigik/VoiceAI/releases): в нём уже есть
`VoiceAI.exe`, библиотеки CUDA и модель Whisper. Распакуйте zip в любую папку и
запустите `VoiceAI.exe`. Архив собирается автоматически (GitHub Actions) по
каждому тегу `v*`; сборка из исходников требует Visual Studio и CUDA Toolkit и
занимает 10+ минут.

## Требования для сборки

### Windows 10/11

- **Rust** — версия зафиксирована в `rust-toolchain.toml`; rustup сам подтянет
  её при первой сборке: `winget install --id Rustlang.Rustup`
- **Visual Studio 2022** (любая редакция или Build Tools) с компонентом
  «Разработка классических приложений на C++» (компилятор MSVC и CMake).
- **Видеокарта NVIDIA** и **CUDA Toolkit 12.8+**:
  `winget install --id Nvidia.CUDA --accept-source-agreements --accept-package-agreements`
  или установщик с https://developer.nvidia.com/cuda-downloads.
- **LLVM/Clang** — нужен `libclang.dll` для генерации привязок bindgen:
  `winget install --id LLVM.LLVM -e --accept-source-agreements --accept-package-agreements`

### Ubuntu 24.04

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake clang libclang-dev pkg-config \
  libasound2-dev libxkbcommon-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libwayland-dev libssl-dev
# Rust: https://rustup.rs — при первой сборке сам подтянет версию из rust-toolchain.toml
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

На Linux распознавание идёт на процессоре (GPU не требуется).

### macOS 15

- **Xcode Command Line Tools** (`xcode-select --install`) — компилятор C и
  `libclang` для bindgen.
- **CMake**: `brew install cmake`
- **Rust**: https://rustup.rs

На macOS распознавание идёт через **Metal** — работает на любом Mac (включая
Apple Silicon).

## Сборка

### Windows

Одной командой — скрипт сам настроит окружение MSVC + CUDA, соберёт релиз и
положит библиотеки CUDA и модель рядом с exe:

```powershell
git clone https://github.com/Pigik/VoiceAI; cd VoiceAI
.\download_models.bat   # модель Whisper, один раз
.\build.bat
```

Готовый файл — `target\release\VoiceAI.exe`; рядом с ним лежат `cublas64_*.dll`,
`cublasLt64_*.dll`, `cudart64_*.dll`, поэтому запускать можно из любой папки.

Сборка в уже открытом терминале требует окружения разработчика:

```powershell
# MSVC (путь зависит от редакции Visual Studio)
& "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
# CUDA (пример для v13.3)
$env:CUDA_PATH = "C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.3"
$env:CUDA_PATH_V13_3 = $env:CUDA_PATH
$env:PATH = "$env:CUDA_PATH\bin;$env:CUDA_PATH\bin\x64;" + $env:PATH

cargo build --release
```

Пути к CUDA v13.3 по умолчанию прописаны в `.cargo/config.toml` (переменные
окружения их перекрывают). При другой версии CUDA поправьте их там.

### Ubuntu 24.04 / macOS 15

```bash
git clone https://github.com/Pigik/VoiceAI && cd VoiceAI
bash build.sh   # соберёт release и положит модель рядом с бинарником
./target/release/VoiceAI
```

Примечание для macOS: при первом запуске система может попросить разрешить
программе «Универсальный доступ» (Accessibility) — без него не работает
глобальная клавиша записи. Вставка текста под курсор реализована только для
Windows; на Linux/macOS текст сохраняется в `output.txt` и в журнал реплик.

## Модели

### Whisper (по умолчанию)

Модель — `ggml-large-v3-turbo.bin` (~1,6 ГБ, f16, лучшая точность для русского,
на видеокарте работает очень быстро). Скачать и **проверить по SHA-256**:

```powershell
.\download_models.bat
```

Скрипт качает модель с HuggingFace (ggerganov/whisper.cpp) и сверяет
контрольную сумму. Если файл уже скачан и хэш совпал — повторно не качает;
повреждённый файл скачивается заново. Вместо HuggingFace можно передать свой
адрес первым аргументом, например последний релиз проекта:

```powershell
.\download_models.bat "https://github.com/Pigik/VoiceAI/releases/latest/download"
```

Вручную (Linux/macOS):

```bash
curl -L -o ggml-large-v3-turbo.bin https://github.com/Pigik/VoiceAI/releases/latest/download/ggml-large-v3-turbo.bin
```

Ожидаемый SHA-256:

```
ggml-large-v3-turbo.bin  1FC70F774D38EB169993AC391EEA357EF47C88757EF72EE5943879B7E8E2BC69
```

Программа ищет модель в таком порядке:

1. Путь из настроек (`model_path` в `config.json` или окно настроек).
2. Переменная окружения `WHISPER_MODEL` (путь к файлу).
3. Папка рядом с исполняемым файлом.
4. Текущая рабочая папка.
5. Папка `models/`.

### GigaAM v3 e2e-ctc (по желанию)

Вторая модель для русской речи (сама расставляет пунктуацию, работает на CPU).
В поставку не входит: в окне настроек выберите «GigaAM v3 e2e-ctc» и нажмите
«Скачать модель» — она скачается один раз (~215 МБ) в папку данных приложения
(`%APPDATA%\VoiceAI\giga-am-v3` или `~/.config/VoiceAI/giga-am-v3`).
Для скачивания нужен `curl` (есть в Windows 10+ и macOS).

## Настройки распознавания

Что влияет на качество текста:

- **GPU-ускорение** (CUDA на Windows / Metal на macOS) с flash-вниманием: на
  RTX 4060 запись расшифровывается примерно за 0,35 с, первый запуск с загрузкой
  модели — 1,5–4 с.
- **Декодинг Whisper**: greedy `best_of=5`, температурный фолбэк отключён — на
  коротких и невнятных записях так меньше «выдуманного» текста. Параметры общие
  для программы и примера (`src/whisper_config.rs`).
- **Предобработка аудио** (`src/audio.rs`): ресемплинг оконным sinc-фильтром
  (без алиасинга), обрезка тишины по краям, нормализация громкости,
  по желанию — шумоподавление. Тихие и пустые записи (случайное нажатие
  клавиши) в модель не отправляются.
- **Пост-обработка текста** (`src/postprocess.rs`): паразиты, повторы,
  пунктуация, абзацы.
- **Язык**: по умолчанию `ru`; `auto` включает автоопределение языка Whisper.
  GigaAM понимает только русский, настройка языка на неё не влияет.

## Конфигурация

Настройки хранятся в человекочитаемом файле `config.json`:

- Windows: `%APPDATA%\VoiceAI\config.json`
- Ubuntu / macOS: `~/.config/VoiceAI/config.json`

Файл лежит вне папки с программой, поэтому установка новой версии поверх
старой не сбрасывает настройки. Он создаётся при **первом запуске** (окно
настроек при этом открывается само). Правки, сделанные в файле вручную,
применяются при следующем запуске.

| Поле | Тип | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `input_device` | строка или `null` | `null` | Имя устройства ввода (`null` — по умолчанию) |
| `press_mode` | `"PushToTalk"` / `"Toggle"` | `"PushToTalk"` | Режим клавиши записи |
| `hotkey` | строка | `"F1"` | Клавиша записи (`"F1"` … `"F24"`) |
| `auto_punctuation` | bool | `true` | Точки, заглавные буквы и абзацы |
| `language` | строка | `"ru"` | Язык распознавания (`auto`, `ru`, `en`, …) |
| `speech_engine` | `"whisper"` / `"gigaam"` | `"whisper"` | Модель распознавания |
| `model_path` | строка или `null` | `null` | Путь к модели Whisper (`null` — автоматический поиск) |
| `auto_start` | bool | `false` | Автозапуск при входе в систему |
| `input_gain` | число от 0 до 4 | `1.0` | Усиление входного сигнала |
| `noise_reduction` | bool | `false` | Подавление фонового шума |
| `keep_audio` | bool | `true` | Сохранять запись в `output.wav`; `false` — расшифровка из памяти |
| `privacy_mode` | bool | `false` | Не сохранять текст расшифровок в журналах |

Если файл повреждён или содержит некорректное значение, программа пишет
понятную ошибку в окно и в `voiceai.log`, использует значения по умолчанию и
открывает окно настроек, где есть кнопка «Сбросить все настройки к значениям
по умолчанию».

Тот же формат используется для **профиля**: окно настроек умеет экспортировать
настройки в указанный файл и импортировать их обратно.

## Запуск

- Запустите `VoiceAI` (на Windows — `VoiceAI.exe`).
- **Зажмите F1** (или выбранную клавишу), говорите, отпустите — текст появится
  под курсором (Windows), а также в `output.txt` и в журнале реплик.
- Первая запись может быть дольше (модель загружается в память один раз),
  дальше — быстро.
- Если речь не распозналась (запись слишком тихая или короткая), программа
  напишет об этом в окне и в `voiceai.log`.
- Повторный запуск `VoiceAI.exe` не запускает вторую копию: программа видит,
  что первая уже работает, сообщает об этом и закрывается.

### Где лежат файлы

| Файл | Где |
| --- | --- |
| `output.wav`, `output.txt`, `voiceai.log` | Папка, из которой запущена программа (при запуске двойным щелчком — папка с exe). Если туда нельзя писать (например, при автозапуске), — папка программы или папка данных приложения |
| `config.json`, `replicas.jsonl` (журнал реплик), модель GigaAM | Папка данных: `%APPDATA%\VoiceAI` или `~/.config/VoiceAI` |

`voiceai.log` при достижении 5 МБ переименовывается в `voiceai.log.old` и
начинается заново. Журнал реплик хранит 200 последних записей.

## Командная строка

```powershell
VoiceAI.exe --help      # справка по аргументам (или -h)
VoiceAI.exe --version   # версия программы (или -V)
```

Без аргументов открывается графическое окно. На Windows программа графическая,
поэтому командная строка не ждёт её завершения и текст справки появляется
после приглашения.

## Оффлайн-установка из архива

```powershell
.\build.bat        # собрать релиз (один раз)
.\package.bat      # создаёт dist\VoiceAI-windows-x64.zip
```

В архив попадают `VoiceAI.exe`, библиотеки CUDA, лицензии и (если есть в
`target\release`) модель Whisper. Архив можно перенести на другой компьютер и
запускать без интернета: распакуйте в любую папку и запустите `VoiceAI.exe`.

## Проверка кода

Формат, статический анализ и тесты — одной командой:

```powershell
.\check.ps1      # Windows (PowerShell)
```

```bash
bash check.sh    # Linux / macOS
```

Скрипт по очереди выполняет:

1. `cargo fmt --all -- --check` — форматирование;
2. `cargo clippy --all-targets -- -D warnings` — статический анализ;
3. `cargo test --all-targets` — все тесты.

Он завершается кодом 0, только если все три шага прошли. Те же проверки
запускает CI (`.github/workflows/ci.yml`) на Ubuntu 24.04 и macOS 15 при каждом
пуше и pull request; форматирование проверяется и на Windows.

## Проверка распознавания без GUI

```powershell
cargo run --release --example transcribe_test -- output.wav
cargo run --release --example transcribe_test -- output.wav auto ggml-large-v3-turbo.bin
cargo run --release --example transcribe_test -- output.wav gigaam
```

Пример повторяет конвейер программы: готовит аудио, загружает модель,
распознаёт и печатает «сырые» сегменты Whisper и итоговый текст после
пост-обработки. Аргументы: `язык` (`ru` / `en` / `auto`, по умолчанию `ru`),
`модель` (путь к .bin) и флаги `gigaam` (распознавать GigaAM) и `raw`
(без обрезки тишины и нормализации). Нужен моно WAV 16 бит — такой пишет сама
программа (`output.wav`).
