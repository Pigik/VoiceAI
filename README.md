# VoiceAI

Диктофон с локальным распознаванием речи через Whisper (whisper.cpp).

## Возможности

- Запись голоса по удержанию клавиши **F1** (работает в любом приложении).
- Автоматическое распознавание речи через Whisper (whisper-rs), полностью локально.
- **Пост-обработка текста**: убираются слова-паразиты («ну», «вот», «как бы», «э-э»), случайные повторы слов, расставляются знаки препинания и заглавные буквы, длинный текст делится на абзацы.
- **Журнал работы** `voiceai.log`: все шаги (сохранение, расшифровка, ошибки) записываются с метками времени — легко понять, что произошло.
- Надёжность: сбой отдельной расшифровки не останавливает программу — следующая запись обработается нормально.
- **Настройки сохраняются на диск** (`config.json` в папке данных пользователя) и переживают обновление программы; первый запуск открывает окно настроек и создаёт файл конфигурации.
- **Язык распознавания и путь к модели** задаются настройками (без пересборки программы).
- **Автозапуск** при входе в систему включается настройкой.
- **Иконка в системном трее** (Windows) показывает состояние: синий — готов к записи, красный — идёт запись.
- **Одна копия**: повторный запуск не запускает второе приложение и не мешает первому.
- **Профиль настроек** можно экспортировать и импортировать (окно настроек).

## Требования для сборки и работы

### Windows 11

- Rust — версия зафиксирована в `rust-toolchain.toml` (1.95.0, MSVC). Проще всего
  установить через [rustup](https://rustup.rs) — он сам подтянет нужную версию
  при первой сборке: `winget install --id Rustlang.Rustup`
- Visual Studio 2022 Build Tools / Community с компонентом «Разработка классических приложений на C++» (нужен компилятор MSVC)
- CMake (входит в комплект Visual Studio)
- **Видеокарта NVIDIA** и **CUDA Toolkit 12.8+** для GPU-ускорения распознавания.
  Установка CUDA:
  - `winget install --id Nvidia.CUDA --accept-source-agreements --accept-package-agreements`
  - или вручную с https://developer.nvidia.com/cuda-downloads (локальный установщик).
- **LLVM/Clang** — нужен `libclang.dll` для генерации привязок bindgen. Установка:
  - `winget install --id LLVM.LLVM -e --accept-source-agreements --accept-package-agreements`

### Ubuntu 24.04

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake clang libclang-dev curl
# Rust: https://rustup.rs — при первой сборке сам подтянет версию из rust-toolchain.toml
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

На Linux распознавание идёт на процессоре (GPU-ускорение не требуется).

### macOS 15

- **Xcode Command Line Tools** (входят в Xcode или ставятся командой
  `xcode-select --install`) — дают компилятор C и `libclang` для bindgen.
- **CMake**: `brew install cmake`
- **Rust**: https://rustup.rs (при первой сборке сам подтянет версию из `rust-toolchain.toml`)

На macOS распознавание идёт через **Metal** — работает на любом Mac (включая
Apple Silicon), видеокарта NVIDIA не нужна.

## Модель Whisper

Рекомендуемая модель для русского языка — `ggml-large-v3-turbo.bin` (~1,6 ГБ, без
квантования, f16). Это лучшая точность для русского, и на видеокарте она работает
очень быстро. Если точная модель не найдена, программа автоматически использует
запасную `ggml-large-v3-turbo-q5_0.bin` (~547 МБ, Q5_0).

Скачать и **проверить по SHA-256** можно одной командой:

```powershell
.\download_models.bat
```

Скрипт скачивает обе модели с HuggingFace и сверяет их контрольные суммы
(константы в самом скрипте). Если файл уже скачан и хэш совпал — повторное
скачивание не выполняется: кеш переиспользуется при следующих запусках.
При повреждённом файле модель скачивается заново.

Вручную (то же самое):

```
curl -L -o ggml-large-v3-turbo.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

Ожидаемые SHA-256:

```
ggml-large-v3-turbo.bin        1FC70F774D38EB169993AC391EEA357EF47C88757EF72EE5943879B7E8E2BC69
ggml-large-v3-turbo-q5_0.bin   394221709CD5AD1F40C46E6031CA61BCE88931E6E088C188294C6D5A55FFA7E2
```

Программа ищет файл модели в таком порядке:

1. Путь из настроек (`model_path` в `config.json` или окно настроек).
2. Переменная окружения `WHISPER_MODEL` (путь к файлу).
3. Папка рядом с исполняемым файлом (сначала `ggml-large-v3-turbo.bin`, затем `ggml-large-v3-turbo-q5_0.bin`).
4. Текущая рабочая папка.
5. Папка `models/`.

Имена файлов моделей заданы константами `MODEL_FILE` и `FALLBACK_MODEL_FILE` в `src/main.rs`.

## Настройки распознавания

Что влияет на качество текста:

- **GPU-ускорение (CUDA на Windows / Metal на macOS)**: инференс идёт на видеокарте
  (flash-внимание включено), 20-секундная запись расшифровывается за долю секунды.
  Тесты на RTX 4060: ~0,35 с на запись, полный запуск с загрузкой модели ~1,5–4 с.
- **Модель**: large-v3-turbo f16 — максимальная точность для русского.
- **Декодинг**: greedy `best_of=5` — несколько проходов, берётся лучший вариант; устойчив к коротким записям.
- **Температурный фолбэк отключён** (`temperature_inc = -1.0`) — на мутных коротких записях повторные проходы дают выдуманный текст.
- **Предобработка аудио** (`src/audio.rs`): качественный ресемплинг окном-синком
  (без алиасинга), тишина в начале/конце обрезается, тихая запись нормализуется по громкости.
- **Пост-обработка текста** (`src/postprocess.rs`): слова-паразиты, повторы, пунктуация, абзацы.
- **Язык**: по умолчанию `ru`; задаётся в настройках (окно настроек или поле `language`
  в `config.json`). Значение `auto` включает автоопределение языка Whisper.

## Сборка

### Windows

Проще всего собрать одной командой — скрипт сам настроит окружение MSVC+CUDA,
соберёт релиз и положит библиотеки CUDA рядом с exe:

```powershell
.\build.bat
```

Готовый файл — `target\release\VoiceAI.exe`. Рядом с ним кладутся `cublas64_1*.dll`,
`cublasLt64_1*.dll`, `cudart64_1*.dll`, поэтому запускать можно из любой папки.

Для сборки в открытом терминале нужно окружение разработчика:

```powershell
# настройка MSVC
& "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
# настройка CUDA (пример для v13.3)
$env:CUDA_PATH = "C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.3"
$env:CUDA_PATH_V13_3 = "C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.3"
$env:PATH = "C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.3\bin;C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v13.3\bin\x64;" + $env:PATH

cargo build --release
```

### Ubuntu 24.04 / macOS 15

```bash
./build.sh   # соберёт release и положит модели рядом с бинарником
```

Готовый файл — `target/release/VoiceAI`. Запуск:

```bash
./target/release/VoiceAI
```

Примечание для macOS: при первом запуске система может попросить разрешить
приложению управлять системой (глобальная клавиша F1 работает через
«Универсальный доступ»/Accessibility). Вставка распознанного текста в активное
окно реализована только для Windows; на Linux/macOS текст записывается в `output.txt`.

## Конфигурация

Настройки сохраняются в человекочитаемый файл `config.json`:

- Windows: `%APPDATA%\VoiceAI\config.json`
- Ubuntu / macOS: `~/.config/VoiceAI/config.json`

Файл лежит вне папки с программой, поэтому установка новой версии поверх старой
(или перезапись папки приложения) не сбрасывает настройки пользователя. Файл
создаётся при **первом запуске** автоматически (окно настроек при этом
открывается само). Правки в файле применяются при следующем запуске — сборка
программы для этого не нужна.

Доступные поля:

| Поле | Тип | Значение по умолчанию | Назначение |
| --- | --- | --- | --- |
| `input_device` | строка или `null` | `null` | Имя устройства ввода (`null` — по умолчанию) |
| `press_mode` | `"PushToTalk"`/`"Toggle"` | `"PushToTalk"` | Режим клавиши записи |
| `auto_punctuation` | bool | `true` | Автоматическая пунктуация |
| `language` | строка | `"ru"` | Язык распознавания (`auto`, `ru`, `en`, …) |
| `model_path` | строка или `null` | `null` | Путь к модели Whisper (`null` — автоматический поиск) |
| `auto_start` | bool | `false` | Автозапуск при входе в систему |

Если файл повреждён или содержит некорректное значение — программа не молчит:
пишет понятную ошибку в окно и в `voiceai.log`, использует значения по умолчанию
и открывает окно настроек, где можно нажать «Сбросить все настройки к значениям
по умолчанию».

Тот же `config.json` используется и как **профиль**: окно настроек умеет
экспортировать профиль в указанный файл и импортировать его (применить
содержимое импортированного файла).

## Запуск

- Запустите `VoiceAI` (на Windows — `VoiceAI.exe`).
- **Зажмите F1** и говорите, отпустите — рядом с записью `output.wav` появится расшифровка `output.txt` (в папке, где была запущена программа).
- Распознавание идёт локально, без интернета. Первая запись может быть
  дольше (модель грузится в память видеокарты один раз), дальше — мгновенно.
- Если речь не распозналась (запись слишком тихая/короткая) — программа об этом напишет в статусе и в `voiceai.log`; текстовый файл всё равно создаётся.
- Любые ошибки дублируются в `voiceai.log` рядом с записью — загляните туда, если что-то не так.
- На Windows в системном трее появляется иконка VoiceAI: синяя — готов к записи,
  красная — идёт запись.
- Повторный запуск `VoiceAI.exe` не запускает вторую копию: программа видит,
  что первая уже работает, пишет об этом в `voiceai.log` и закрывается, не
  трогая первую.

## Оффлайн-установка из архива

Собранный релиз можно упаковать в автономный zip-архив:

```powershell
.\build.bat        # собрать релиз (один раз)
.\package.bat      # создаёт dist\VoiceAI-windows-x64.zip
```

В архив попадают `VoiceAI.exe`, библиотеки CUDA и (если есть в `target\release`)
модели. Такой архив можно скопировать на другой компьютер и установить/запускать
полностью без интернета: распакуйте zip в любую папку и запустите `VoiceAI.exe`.

## Тесты

```powershell
cargo test         # модульные тесты (пост-обработка и аудио)
cargo clippy --all-targets -- -D warnings   # статический анализ
```

Те же команды работают на Ubuntu и macOS (без префикса `.\`).

## Проверка распознавания без GUI

```powershell
cargo run --example transcribe_test -- test_russian.wav
cargo run --example transcribe_test -- output.wav ru ggml-large-v3-turbo.bin raw greedy
```

Пример повторяет весь конвейер приложения: загружает модель, готовит аудио,
распознаёт и печатает и «сырые» сегменты Whisper, и итоговый текст после
пост-обработки. Аргументы: `язык` (`ru`/`en`/`auto`, по умолчанию `ru`),
`модель` (путь к .bin), `raw` (пропустить предобработку аудио),
`greedy` (включить greedy-декодинг вместо beam search).

## Непрерывная интеграция (CI)

В репозитории есть GitHub Actions workflow (`.github/workflows/ci.yml`), который
при каждом пуше и pull request автоматически проверяет форматирование, запускает
`cargo clippy -- -D warnings` и модульные тесты на **Windows**, **Ubuntu 24.04** и
**macOS 15** — это гарантирует, что код всегда чистый и собирается на всех трёх
платформах.
